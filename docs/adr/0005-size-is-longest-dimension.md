# Size is the longest dimension

The Size Attribute needs one comparable number per noun, and Ghosts need a true real-world scale. We decided Size is the longest dimension, in metres, of a typical example of the noun, and that a Ghost is drawn so its longest dimension matches it. One number then serves both, so Feedback and the Ghost beside the hidden Daily Object can never disagree. A curator can also measure it from a model or a tape measure without having to define a volume.

## Considered Options

- **Volume** — rejected: closer to "bulk", but undefined for hollow or irregular objects (a mug, a chair: material or enclosed space?), and Ghosts would still need a second number for scale.
- **Height as usually placed** — rejected: every noun would need an orientation decision, and objects that stand or lie flat (a broom, a rug) get arbitrary values.

## Consequences

- Long thin objects read as big: a pencil is bigger than a coffee mug. The Ghost at true scale shows the player why.
- Every noun's Size is judged against a typical example, not the specific sourced model, as Primary Material is (ADR-0003).
